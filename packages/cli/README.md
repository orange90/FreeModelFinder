# FreeModelFinder CLI

FreeModelFinder discovers free LLM models and exposes them through a local OpenAI, Anthropic and Gemini compatible gateway with a built-in web UI.

```bash
npm install -g freemodelfinder
fmf serve --open
```

The gateway and UI run at `http://127.0.0.1:11435` by default. See the [project README](https://github.com/orange90/FreeModelFinder#readme) for provider setup, API examples and security notes.
